# ADR-001 — 재무 데이터 로컬 저장 (Beelink)

- **상태**: Accepted
- **일자**: 2026-04-15 (FS-2026-001 판정 시)
- **관련**: URD v0.2 NFR-02, FS-2026-001

## 맥락
시중 재무 앱은 SaaS 중심으로 거래·잔액·세제 정보를 벤더 클라우드에 저장한다. 본 프로젝트는 반도체 설계 직군 개인의 급여·투자·부채 등 민감 금융 데이터를 다루며, 외부 유출 시 복구 불가능한 피해가 발생한다. 동시에 단일 사용자 환경이므로 SaaS의 확장성 이점은 필요하지 않다.

## 결정
재무 데이터(`transactions`, `budgets`, `tax_deductions`, `tax_rules*`)는 **Beelink SER9 Pro 로컬 PostgreSQL에만 저장**한다. 클라우드(Supabase)에는 절대 저장·동기화하지 않는다.

## 결과
**긍정**
- 제3자 데이터 접근 경로 원천 차단
- 세법·금융 규제 변화에 대한 데이터 주권 확보
- 월 운영비 절감 (DB 요금 0원)

**부정 / 비용**
- 하드웨어 단일 장애점 → §8 백업·Runbook으로 완화
- 외부 접근에 Cloudflare Tunnel 필요 (ADR-004)
- PM 데이터와 물리 FK를 맺을 수 없음 → `auth_user_id` 논리 참조

## 대안
1. **Supabase 단일 DB + RLS**: 관리 편의성은 높지만 최우선 품질속성인 기밀성 위배.
2. **자체 VPS + 관리형 PostgreSQL**: 월 비용 증가, 물리적 격리 미달.
3. **SQLite 로컬**: 동시성·`pgcrypto` 미지원으로 탈락.
